# 여러 칸짜리 지형 덩어리

클로이가 만든 지형 GLB 13개입니다. 한 칸짜리 조각이 아니라 3×3, 5×5칸 덩어리라서
`assets/models/terrain/`(한 칸 조각 자동 인식 폴더)에 두면 한 칸 크기로 찌그러져 보입니다.
그래서 따로 보관합니다.

**전투 섬에 쓰는 것:** cove·spit(바닷가, 앞쪽 -Z가 바다), saddle·terraces·ravine(섬 안쪽).
섬 생성기가 `tiles.json`의 칸 높이(surface_y ÷ 0.5 = 단)를 섬 격자에 그대로 찍고 그 자리에 모델을 놓습니다.
그래서 모델 모양과 이동 규칙(같은 높이 또는 계단)이 정확히 맞습니다. 섬마다 바닷가 덩어리 1개(75%), 반지름 7 이상이면 안쪽 덩어리 1개.
쓰는 목록은 `scripts/island/terrain_chunks.gd`의 `USE` 표에서 바꿉니다. 나머지(둑길, 사다리, 관문, 암초 등)는 아직 안 씀.
