# 타일 GLB 배치표

거리 단위는 m, 위는 +Y, 정면은 -Z입니다. 각 모델의 로컬 (0,0,0)이 격자 배치 기준입니다. tiles.json의 x,z는 칸 중심이며 surface_y는 모델 바닥을 기준으로 한 표면 높이입니다. null은 보행 표면이 없는 칸입니다.

지형 모델은 해당 범위의 타일 외형을 대체합니다. 관문은 기존 지면에 얹습니다. 타일 위에 배치할 때 모델 바닥의 월드 높이를 로컬 높이에 더합니다. 이동 및 상륙 데이터와 충돌체는 게임에서 별도로 연결합니다. 경사로의 surface_y는 각 칸의 중앙 높이입니다.

| 파일 | 구성 | 접근 방향 | 배치 |
|---|---|---|---|
| cove.glb | 초승달 만 | -Z, 중앙 수면 | 오목한 해안의 낮은 모래 칸을 상륙 후보로 사용. |
| spit.glb | 모래톱 곶 | -Z, 곶 끝 | 좁은 곶에서 안쪽으로 폭이 넓어지는 모래 지형. |
| saddle.glb | 안부 고개 | -Z / +Z | 양쪽 능선 사이의 중앙 통로. |
| terraces.glb | 층단형 고지 | -X / +X | 양쪽 낮은 단에서 중앙 고지로 접근. |
| ravine.glb | 협곡 | -Z / +Z | 가운데 한 칸 폭의 협곡 바닥과 양옆의 높은 벽. |
| reef.glb | 연안 암초대 | 해상 장애물 | 선박 접근 제한용 마스크. 해상 이동은 별도 연결. |
| causeway.glb | 돌 둑길 | -Z / +Z | 수면을 가로지르는 한 칸 폭 둑길. |
| switchback.glb | 지그재그 목재 경사로 | -Z, 좌측 하단 / 우측 상단 | 좌우 경사 구간은 칸당 0.5m 상승. 회전참 표면은 1.5m이므로 경사면 높이 보간 또는 연결점 설정 필요. |
| boardwalk.glb | 꺾인 습지 보행로 | -Z / +X | 직각으로 이어진 다섯 칸. |
| gate.glb | 목책 관문 | -Z / +Z | 기존 땅 위에 배치. 가운데 칸만 통과. |
| jettywall.glb | 돌 방파제 | 해상 장애물 | 선박 접근 제한용 마스크. 해상 이동은 별도 연결. |
| ladder.glb | 절벽 사다리 | -Z 아래 → 중앙 위 | 1.5m 고저차. 별도 등반 링크 필요. +Z 예약 칸은 배치 여백. |
