# 그래픽 제작 안내

ChatGPT는 2D 그림을 그리지만 게임용 3D 모델은 직접 만들지 못합니다. 그래서 아래 3단계를 거칩니다.

```
ChatGPT (컨셉 아트) → Meshy / Tripo / Blender (3D 변환) → assets/models/*.glb (게임에 자동 적용)
```

## 1단계. 스타일 가이드부터 (ChatGPT)

먼저 아래 내용을 ChatGPT에 붙여 넣어 톤을 정하세요. 모든 그림이 같은 느낌으로 나옵니다.

> 섬 방어 실시간 전술 게임의 아트 스타일 가이드를 만들어 줘.
> 조건: 로우폴리 3D, 단순한 형태, 큰 실루엣, 색상 팔레트 8색 이내(hex 코드로), 위에서 45도로 내려다보는 카메라.
> 결과물: 스타일 설명 5줄, 팔레트, 그리고 섬 전체 분위기 컨셉 아트 1장.

마음에 드는 결과가 나오면 그 팔레트를 저에게도 알려 주세요. 임시 도형 색을 거기에 맞춰 둘게요.

## 지형 조각 (섬 타일) — 지금은 안 씀

> 2026-11-26부터 섬은 "윗면은 코드로 한 장 + 절벽은 바위 조각(rock_kit)" 방식으로 그립니다.
> 아래 칸 타일 방식은 `terrain_builder.gd` 의 `STYLE = "pieces"` 로 바꿀 때만 쓰입니다.
> 새로 만들 지형 모델은 [TERRAIN_KIT.md](TERRAIN_KIT.md)를 보세요.

`assets/models/terrain/` 폴더에 넣으면 전투 섬과 본 섬 타일이 자동으로 바뀝니다. 없으면 지금처럼 상자 타일입니다.

- **파일 이름에 아래 단어가 들어 있으면** 그 모양으로 씁니다. 대소문자, 숫자, `_` `-` 상관없음. 예: `Terrain_Bay_02.glb`, `CliffCorner.glb`
- 같은 모양 파일이 여러 개면 칸마다 섞어 씁니다(예: `flat_01`, `flat_02`).
- 모델은 칸 **맨 위 한 단**(가로 1 × 높이 0.5 × 세로 1)에 딱 맞게 늘려 붙이고, 그 아래는 흙기둥 상자로 채웁니다.
- **그림만 바뀝니다.** 어디로 걸을 수 있는지는 그대로 "같은 높이 또는 계단"입니다. 모델에 길처럼 보이는 홈이 있어도 계단이 없으면 못 지나갑니다.
- 윗면은 **평평하게** 만들어 주세요. 모델 전체 높이를 0.5에 맞추기 때문에 위로 튀어나온 장식(나무, 돌기둥 등)이 있으면 땅이 그만큼 낮아져 병사가 파묻혀 보입니다. 나무·바위는 따로 놓습니다.
- 계단이 놓인 면은 절벽으로 치지 않습니다(계단 위 칸에 절벽 조각이 오지 않음). 해변 조각은 바다가 한 면뿐인 칸에만 쓰고, 해변에는 절벽 벽을 붙이지 않습니다.
- 이름을 알아보지 못한 파일은 게임을 켤 때 경고로 이름이 나옵니다.

| 모양 | 이름에 넣을 단어 (하나만) | 언제 쓰나 | 기본 방향 (이 방향으로 만들기) |
|---|---|---|---|
| 평지 | `flat`, `plain`, `grass`, `plateau` | 사방이 같은 높이 | 방향 없음 |
| 곧은 절벽 | `edge`, `cliff`, `side`, `straight` | 한 면만 낮음 | 낮은 쪽이 -Z |
| 바깥 모서리 | `corner`, `outer` | 이웃한 두 면이 낮음 | -Z, -X 쪽이 낮음 |
| 만(안쪽 모서리) | `bay`, `cove`, `inner` | 면은 막혔고 대각선 하나만 낮음 | -X-Z 대각선이 낮음 |
| 좁은 능선 | `narrow`, `ridge`, `bridge` | 마주 보는 두 면이 낮음 | -Z, +Z 쪽이 낮음 |
| 곶 | `cape`, `peninsula`, `tip` | 세 면이 낮음 | 끝이 -Z (-Z, -X, +X가 낮음) |
| 외딴 기둥 | `islet`, `pillar` | 네 면이 다 낮음 | 방향 없음 |
| 협곡 바닥 | `canyon`, `gorge`, `valley` | 양옆(마주 보는 두 이웃)이 더 높음 | -X, +X 쪽이 높은 벽, 길은 Z 방향 |
| 해변 | `beach`, `sand`, `coast` | 높이 1인 바닷가 칸(배가 닿는 곳) | 바다 쪽이 -Z |

모양 파일이 없으면 평지 조각으로 대신합니다. 모델이 반대쪽을 보고 있으면 `asset_library.gd`의 `TERRAIN_TURN` 표에 `{"bay": 2}`처럼 적으면 돌아갑니다(90도 단위).

## 3단계. 3D 변환

**쉬운 방법: Meshy(meshy.ai) 또는 Tripo(tripo3d.ai)**
1. 정면 그림을 Image to 3D에 올립니다.
2. 옵션에서 **Low poly**(가능하면 폴리곤 5,000개 이하)를 고릅니다.
3. **GLB** 형식으로 내려받습니다.

**Blender로 다듬기 (크기나 방향이 이상할 때)**
- 모델의 **바닥 중앙**이 원점(0,0,0)에 오게, **앞쪽이 -Z** 방향을 보게 맞춥니다.
- 위 표의 크기에 맞게 스케일을 조절합니다.
- `File > Export > glTF 2.0` → 형식 **glTF Binary (.glb)**.

ChatGPT에 "이 그림대로 Blender 파이썬 스크립트로 로우폴리 모델을 만들어 줘"라고 시키는 방법도 있지만, 결과 품질은 들쭉날쭉합니다.

## 움직이는 3D 병사 (뼈대 + 동작)

병사는 지금 **뼈대(리깅)와 동작(애니메이션)이 들어 있는 3D 캐릭터**로 그립니다. 걷기·뛰기·공격·맞음·막기·쓰러짐 동작이 섞여서(블렌딩) 자연스럽게 이어집니다.

- 임시 캐릭터: `assets/characters/kaykit/` 의 무료 캐릭터(KayKit Adventurers, 제작 Kay Lousberg, **CC0** = 상업용 포함 자유 사용, 출처 표기 의무 없음. `LICENSE.txt` 참고).
  아군 = 기사(Knight)·두건 도적(Rogue_Hooded), 적 = 야만전사(Barbarian)·도적(Rogue)을 붉게 물들여 씀.
- 어떤 병사가 어떤 캐릭터·무기·동작을 쓰는지: `scripts/core/asset_library.gd` 의 `RIGS`(캐릭터·장비·색), `RIG_ANIMS`(동작 이름) 표.
- 동작을 움직이는 코드: `scripts/core/rig_actor.gd`. 시간은 전투가 넘겨 주므로 일시정지·슬로모션 때 동작도 같이 멈춥니다.

**내 캐릭터로 바꾸기 (Mixamo 추천)**
1. Meshy/Tripo로 만든 병사 모델(.fbx 또는 .obj)을 [mixamo.com](https://www.mixamo.com)에 올리면 자동으로 뼈대를 심어 줍니다(무료, Adobe 계정 필요).
2. 아래 동작을 골라 같은 캐릭터로 내려받습니다(In Place 체크). 이름에 이 단어가 들어 있으면 게임이 알아서 찾습니다.
   | 동작 | 이름에 들어갈 단어 (하나) |
   |---|---|
   | 서 있기 | `idle` |
   | 걷기 / 뛰기 | `walk` / `run` |
   | 공격 | `attack`, `slash`, `stab`, `swing` |
   | 활 겨누기 / 쏘기 | `aim` / `shoot` |
   | 맞음 / 방패로 막기 | `hit` / `block` |
   | 쓰러짐 | `death`, `die` |
   | 환호(이겼을 때) | `cheer`, `victory` |
3. Blender에서 동작들을 한 파일로 합쳐 `.glb`로 내보내고 `assets/models/<병사 id>.glb`(예: `infantry.glb`)로 넣습니다. 앞쪽은 -Z.
4. 끝. 파일에 동작이 들어 있으면 자동으로 움직이는 병사가 되고, 크기는 위 표 크기에 맞춰집니다.
   공격 동작의 "칼이 닿는 순간"을 정확히 맞추고 싶으면 `rig_actor.gd`의 `IMPACT` 표에 동작 이름과 초를 적어 주세요(없으면 동작 길이의 40% 지점으로 봄).

찾는 순서: `assets/models/<id>.glb` → `assets/characters/` 3D 캐릭터 → `assets/sprites/` 2D 그림 → 임시 도형.

## 2D 병사 그림 (8방향 스프라이트, 예전 방식)

3D 캐릭터 대신 `assets/sprites/` 의 8방향 그림을 쓸 수 있습니다(위 3D 캐릭터 파일이 없을 때만). 병사 .glb가 있으면 .glb가 먼저입니다.

- 그림 한 장 = 가로 14칸 × 세로 8줄, 한 칸 144px. 줄 = 보는 방향(정면, 오른쪽 앞, 오른쪽, … 왼쪽 앞), 칸 0~3 서기, 4~9 공격, 10~13 맞음.
- 파일 이름: `ally-sword|bow|spear-basic|veteran|elite.png`, `enemy-sword|bow|spear-...png`
- 아군은 지휘관 레벨에 따라 그림이 바뀝니다(Lv1~2 basic, Lv3 veteran, Lv4 elite).
- 어떤 병사가 어떤 그림을 쓰는지는 `scripts/core/asset_library.gd` 의 `SPRITES` 표에서 바꿉니다.

## 4단계. 게임에 넣기

- 파일을 `assets/models/` 폴더에 위 표의 이름 그대로 넣으면 끝입니다. 코드는 건드리지 않아도 됩니다.
- 파일이 없으면 게임은 자동으로 임시 도형을 씁니다.
- 크기와 원점은 자동으로 맞춥니다. 모델의 바닥 넓이(가로·세로)가 위 표 크기에 들어가도록 비율을 유지해 줄이거나 키우고, 바닥 가운데를 원점으로 옮깁니다. 계단처럼 높이가 정확해야 하는 것은 `asset_library.gd` 의 `MODEL_FIT` 표에서 따로 정합니다(방향이 반대인 모델도 여기서 돌립니다).
- 직접 넣기 어렵다면 GitHub에 올리거나 저에게 파일을 주세요. 제가 넣고 크기를 맞출게요.
