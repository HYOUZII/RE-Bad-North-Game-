# Isle Defense (가제)

작은 섬을 침략자로부터 지키는 실시간 전술 로그라이크입니다. Bad North 같은 장르에서 영감을 받은 **오리지널** 프로젝트로, 원작의 이름, 아트, 레벨, 음악은 쓰지 않습니다.

- 엔진: **Godot 4.3 이상** (GDScript)
- 대상: Windows PC

## 바로 실행하기

1. [docs/SETUP.md](docs/SETUP.md)를 따라 Godot과 GitHub Desktop을 설치합니다.
2. Godot에서 이 폴더의 `project.godot`를 엽니다(Import).
3. 오른쪽 위 ▶ 버튼(또는 F5)을 누르면 타이틀 화면이 나옵니다. "새 원정 시작" → 지도에서 빛나는 섬 클릭.

## 게임 방법

- 섬마다 침략자의 배가 몇 차례(웨이브) 몰려옵니다. 모든 웨이브를 막으면 섬 방어 성공. **집이 모두 불타면 패배**입니다. 배는 바다로만 다닙니다.
- 적은 길을 따라 가장 가까운 집부터 노리고, 길을 막는 병사와만 싸웁니다.
- **분대 위 숫자를 좌클릭**(또는 숫자키) → **가고 싶은 칸을 좌클릭**하면 이동합니다. 분대를 고르는 동안은 시간이 느려집니다. 한 칸에는 한 분대만 설 수 있고(못 가는 칸은 빨간 표시), 가는 길은 점선으로 보입니다. 분대를 고른 상태에서 다른 분대로 바꾸려면 그 분대의 숫자를 누르세요.
- 전투는 자동입니다. 이동 중(행군 중)인 분대는 싸우지 않으니, 적과 붙은 상태에서 움직이면 위험합니다.
- 섬은 여러 층의 고원으로 되어 있습니다. **높이가 다른 칸 사이는 절벽**이라 지나갈 수 없고, **계단(주황색 디딤돌)으로만** 오르내립니다. 회색 바위 칸도 못 지나갑니다. 계단과 좁은 길목을 막는 것이 핵심입니다.
- 절벽 너머로는 칼이 닿지 않습니다(화살은 닿음).
- **높은 곳**에서 싸우면 피해가 늘고, 궁수는 사거리도 늘어납니다.
- 적을 **바다로 밀어내면 즉사**합니다. 창병과 거한은 넉백이 강합니다(아군도 떨어질 수 있음).
- 병종 상성: 방패(보병, 방패 약탈자)는 화살에 강하고, 화살은 창병에 강하고, 창병은 방패와 거한에 강합니다. 궁수는 배에 탄 적도 쏠 수 있습니다.
- **F 키**: 선택한 분대의 기술. 숫자는 `scripts/core/catalog.gd`에서 바꿀 수 있습니다.
  - 보병 **방패 돌격**(4초, 재사용 22초): 가장 가까운 적에게 돌진, 몸에 부딪힌 적은 피해 + 크게 밀려남(해안이면 바다로). 화살을 막음.
  - 궁수 **일제 사격**(4초, 재사용 20초): 즉시 한 발씩 쏘고, 4배 빠르게, 30% 멀리, 화살이 적을 3배 세게 밀침. 사거리 안에 적이 없으면 못 씀.
  - 창병 **창벽**(5초, 재사용 22초): 쓰는 순간 주변 1.2m 적을 밀쳐 냄, 이후 공격력 1.5배·넉백 1.8배·거의 안 밀림.
- **G 키**: 장비 사용(화약 단지, 뿔나팔은 전투마다 1번). 못 쓰는 상황이면 버튼에 이유가 나옵니다.
- 분대를 **멀쩡한 집 칸**에 세워 두면 쓰러진 병사가 하나씩 돌아옵니다.
- 섬을 지키면 남은 집 수만큼 **골드**를 받습니다. 지도 화면에서 쓰는 곳:
  - 레벨업(병사 +1, 체력·공격력 상승), 민병 승급, 병종 기술 배우기
  - 상점에서 장비 사기(지휘관 한 명에 하나, 한 번 달면 못 뗌), 새 지휘관 고용
- 한 섬에는 **최대 4개 분대**만 출전합니다(지휘관 카드의 '출전' 체크).
- 분대가 전멸하면 그 지휘관은 **영영 사라집니다**. 섬을 잃으면(집 전소 또는 출전 분대 전멸) 보상 없이 그 섬을 지나 다음으로 갑니다(지도에 ✖). 모든 지휘관을 잃으면 원정 실패, 맨 오른쪽 성채를 지키면 승리.

조작: 우클릭 드래그 또는 Q/E 회전, 휠 확대/축소, Space 일시정지, Esc 선택 해제, F 기술, G 장비.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `scenes/` | 씬 파일. `main.tscn`이 시작 씬 |
| `scripts/core/` | 공용 기능. `asset_library.gd`(모델 불러오기), `game_state.gd`(원정 진행 상태: 골드, 지휘관, 지도) |
| `scripts/island/` | 절차적 섬 생성 |
| `scripts/battle/` | 전투: 유닛(`unit.gd`), 분대, 배, 집, 화살, 웨이브 구성, 길찾기, 능력치 표(`unit_defs.gd`) |
| `scripts/ui/` | 원정 지도 화면 |
| `tests/` | 자동 플레이 테스트(`smoke_test.tscn`), 스크린샷 도구 |
| `scripts/camera/` | 카메라 조작 |
| `scripts/ai/` | 게임 실행 중 AI 모델 호출 (`AI.ask(...)`) |
| `assets/models/` | 직접 만든 3D 모델(.glb)을 넣는 곳 |
| `docs/` | 설치, 그래픽 제작, AI 연동 안내서 |

## 개발 단계

1. ✅ 환경 준비: 프로젝트 뼈대, 섬 생성, 모델 교체 구조, AI 연동 계층
2. ✅ 전투: 분대 3종, 적 상륙 웨이브, 클릭 이동, 자동 전투, 고지대 보너스, 넉백·바다 추락, 집 방어
3. ✅ 로그라이크 루프: 캠페인 지도, 골드, 업그레이드, 퍼마데스
4. v1.0 마무리: 직접 플레이 피드백 반영, 밸런스, Windows 빌드
5. v1.1 손맛: 타격 효과, 화면 흔들림, 효과음 (전투 신호 `unit_hit`, `unit_died` 등에 연결)

## 밸런스 바꾸기

- 병종·적 능력치: `scripts/battle/unit_defs.gd`
- 웨이브 구성과 난이도 곡선: `scripts/battle/wave_director.gd`
- 고지대 보너스, 시간 느려짐 등 규칙 숫자: `scripts/battle/battle.gd` 맨 위
- 골드 비용, 지도 크기: `scripts/core/game_state.gd` 맨 위
- 기술·장비 효과와 가격: `scripts/core/catalog.gd`
- 섬 모양(높이 층 수, 고원 크기, 바위 수): `scripts/island/island_generator.gd`

## 자동 테스트

컴퓨터가 지휘하며 원정 전체를 끝까지 진행합니다. 마지막에 `SMOKE_TEST_DONE`이 나오면 통과입니다.

```
Godot_v4.x.exe --headless --path . --fixed-fps 60 res://tests/smoke_test.tscn -- --runs=5
```
